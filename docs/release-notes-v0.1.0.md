# MathGame Android v0.1.0

MathGame 的首个 Android 可安装预览版。

## 游戏内容

- 完整数独流程：难度选择、题号进入、候选笔记、提示、暂停、存档和结算。
- 算术填字四档难度：可变长度关系、精确分数与小数、比较符以及 `a、b、c` 变量。
- 算术填字使用全局线性关系网络生成，并保证至少存在一组完整解。
- 每日任务支持数独或算术填字任选其一完成签到与补签。
- 全勤奖杯按完成进度和补签次数显示金、银、铜等级。

## Android 信息

- 应用 ID：`com.alexqfmm.mathgame`
- 固定竖屏，复用与 Web 相同的离线游戏逻辑和本地存档。
- 本 APK 使用 debug 签名，面向直接安装和真机验证，不是应用商店正式签名包。

安装新版遇到签名不一致时，需要先卸载旧测试版；卸载会清除应用本地记录。
