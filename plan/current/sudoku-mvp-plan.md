# Sudoku MVP Plan

## 目标

完成一个可离线、无广告、能在 Android 手机上长期使用的标准 9×9 数独。MVP 不追求活动、排行和社交功能，优先保证棋盘手感、题目可靠性和提示可信度。

## 范围

### 基础棋盘

- [ ] 展示 9×9 棋盘和 3×3 宫边界。
- [ ] 预设数字不可修改。
- [ ] 选择空格或用户已填格。
- [ ] 高亮同行、同列、同宫。
- [ ] 高亮与选中数字相同的所有格子。
- [ ] 支持普通输入和笔记输入。
- [ ] 一个格子可以保存多个笔记。

### 输入规则

- [ ] 普通输入支持严格模式：与答案不符时提示错误并拒绝或标记，具体行为在 UI 实现前最终确认。
- [ ] 笔记与同行、同列或同宫的既有数字明显冲突时，振动并拒绝写入。
- [ ] 正式填入正确数字后，可按设置自动删除相关区域中的同数字笔记。
- [ ] 擦除只能作用于用户内容。
- [ ] 撤销需要完整恢复显式输入和由该输入触发的自动笔记清理。

### 提示

- [ ] 提示优先寻找当前盘面可证明的下一步，不直接读取答案生成假理由。
- [ ] 首批技巧包括格内唯一、行内唯一、列内唯一和宫内唯一。
- [ ] 提示结果包含目标格、数字、技巧类型和结构化排除依据。
- [ ] 第一次提示只高亮和解释；用户确认后再自动填写。
- [ ] 如果当前盘面存在错误输入，先指出错误，不继续基于错误盘面推理。
- [ ] 没有基础技巧可用时，明确告知将直接揭示一个格子，不伪装成逻辑结论。
- [ ] 结算记录提示次数，但不通过广告或付费限制提示。

### 会话与完成

- [ ] 计时和暂停。
- [ ] 暂停时遮住棋盘。
- [ ] 自动保存未完成棋局。
- [ ] App 被系统挂起或关闭后可以继续。
- [ ] 81 格全部正确时自动结束计时并进入结算。
- [ ] 结算至少显示难度、用时、错误数和提示数。

### 题目

- [ ] 每道题都通过解数量检查，保证唯一解。
- [ ] 第一阶段允许使用本地固定题库，以便先完成交互。
- [ ] 后续加入完整终盘生成、挖空和唯一解验证。
- [ ] 难度不能只按空格数量判断；至少结合逻辑技巧或求解复杂度。

### Android

- [ ] 完全离线启动和游玩。
- [ ] 锁定竖屏。
- [ ] 错误、选择和完成使用不同强度的 Haptics。
- [ ] 正确处理系统返回键、进入后台、恢复和屏幕锁定。
- [ ] 常见 Android 分辨率下棋盘和数字键没有裁切。
- [ ] 构建可安装的 debug APK。

## 实现阶段

### Phase 0：工程基座

- [x] pnpm workspace
- [x] Web 应用
- [x] 320×640 逻辑视口
- [x] game-core / sudoku-core 边界
- [x] Capacitor 配置
- [x] README、架构、UI 和 MVP 计划文档

### Phase 1：数独领域核心

1. 定义不可变题面和可变会话状态。
2. 实现行、列、宫索引与合法性检查。
3. 实现候选数计算。
4. 实现求解器和解数量上限为 2 的唯一解验证。
5. 为每个规则补固定题盘单元测试。

完成标准：核心包不依赖 UI，给定棋盘能稳定返回候选数、解和合法性。

### Phase 2：可玩棋盘

1. 实现棋盘、数字键和模式切换。
2. 实现选择、高亮、输入、笔记、擦除和撤销。
3. 实现错误反馈、自动清笔记和完成判断。
4. 实现计时、暂停与本地恢复。

完成标准：浏览器中可以完整完成一局固定题目，刷新后能恢复。

### Phase 3：可解释提示

1. 建立候选矩阵。
2. 按格内唯一、行唯一、列唯一、宫唯一顺序寻找步骤。
3. 返回结构化 proof，不直接返回拼好的中文字符串。
4. UI 根据 proof 高亮目标和排除来源，并生成中文说明。
5. 加入“当前错误”和“只能直接揭示”的明确分支。

完成标准：每条提示都能由当前盘面独立复算，文案引用的行、列、宫和阻挡数字真实存在。

### Phase 4：题目与难度

1. 先接入经过验证的离线题集。
2. 实现完整终盘生成器。
3. 实现挖空和唯一解检查。
4. 建立初级、中级、高级的可重复难度评分。

完成标准：连续生成的题目均有唯一解，同一评分规则的结果稳定。

### Phase 5：Android 验收

1. 生成 Android 工程并锁定 portrait。
2. 接入 Haptics adapter。
3. 验证生命周期与存档。
4. 在真机验证触控尺寸、缩放和安全区域。
5. 生成 debug APK，并记录可复现的发布命令。

## 非目标

MVP 暂不包含：

- 登录、云同步、排行榜
- 每日任务和活动系统
- 广告、金币、体力和订阅
- 多人玩法
- iOS 发布
- Electron 桌面发布
- 高级提示技巧的完整百科

## 后续游戏扩展

当数独 MVP 稳定后，再评估第二个数学小游戏。新增游戏时应创建新的 `<game>-core` 包和 Web 页面，只共享应用壳、设置、存档接口、触觉反馈和通用 UI，不复用数独领域类型。
